# 📖 About

WritoShop is a modern full-stack bookstore designed to provide a clean and intuitive experience for discovering and purchasing digital books.

The platform focuses on speed, simplicity and scalability while maintaining a premium UI inspired by modern ecommerce platforms.

The project is being developed with production-ready architecture so new modules such as authentication, order management, payment gateways and an admin dashboard can be added without major refactoring.

# 💻 Getting Started

Clone the repository

```bash
git clone https://github.com/Samir7631/writoshop.git
```

Move into project

```bash
cd writoshop
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Production Build

```bash
npm run build
```

Preview Build

```bash
npm run preview
```
